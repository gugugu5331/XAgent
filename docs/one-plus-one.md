# 为什么 1 + 1 = 2

## 一、直观理解

把 1 个苹果与另 1 个苹果放在一起，数一数，是 2 个苹果。这是我们从小建立的最朴素的加法直觉：加法就是"合并后再计数"。

## 二、基于皮亚诺公理的严格推导

现代数学中，自然数由 **皮亚诺公理（Peano Axioms）** 定义。核心构造如下：

1. `0` 是一个自然数。
2. 每个自然数 `n` 都有一个后继 `S(n)`，也是自然数。
3. `0` 不是任何自然数的后继。
4. 若 `S(a) = S(b)`，则 `a = b`。
5. 数学归纳原理。

在这套公理下，自然数的定义为：

```
1 := S(0)
2 := S(1) = S(S(0))
```

加法通过递归定义：

```
a + 0     := a           （定义 A1）
a + S(b)  := S(a + b)    （定义 A2）
```

## 三、推算 1 + 1

按定义逐步展开：

```
1 + 1
= 1 + S(0)          （因为 1 = S(0)）
= S(1 + 0)          （由 A2：a + S(b) = S(a + b)，取 a=1, b=0）
= S(1)              （由 A1：a + 0 = a）
= 2                 （因为 2 定义为 S(1)）
```

因此：

```
1 + 1 = 2
```

## 四、集合论视角（冯·诺依曼构造）

在 ZFC 集合论中，自然数可用集合层层构造：

```
0 := ∅
1 := {0}       = {∅}
2 := {0, 1}    = {∅, {∅}}
```

加法可以理解为"不相交并集的基数"。设 `A = {a}`（基数为 1），`B = {b}`（基数为 1），且 `A ∩ B = ∅`，则：

```
|A ∪ B| = |{a, b}| = 2
```

即 1 + 1 = 2。

## 五、一个有趣的历史注脚

罗素与怀特海在《数学原理》（Principia Mathematica）中，用了近 **300 多页** 才严格证明 "1 + 1 = 2"，并在旁注中写道："以上命题偶尔有用。"

## 结论

- 从直觉：合并计数。
- 从皮亚诺公理：`1 + 1 = 1 + S(0) = S(1 + 0) = S(1) = 2`。
- 从集合论：两个单元素不相交集合的并的基数为 2。

三种视角互相印证，`1 + 1 = 2` 成立。
