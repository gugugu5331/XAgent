XAgent · Agent Runtime Architecture

把模型的不确定意图，转化为受控、可恢复、可扩展的工程执行

统一运行闭环

  • • 一个 Agent Loop 连接模型、工具与结果
  • • App/TUI 只持有安全投影，不持有执行能力
  • • Provider 层隔离不同模型协议

确定性安全边界

  • • 模型意图经过 Schema、权限和一次性 Ticket
  • • 文件系统、超时、输出和脱敏均在本地控制
  • • 不确定时保留现场，优先保护用户成果

长任务与多 Agent

  • • 会话恢复、上下文压缩与大型结果外置
  • • Defined/Fork 子 Agent 和有界结果 Inbox
  • • Git Worktree 隔离并行修改
